# Drive Smart

Учебное веб-приложение по ПДД в формате мини-игр для подростков и начинающих водителей.

## Основные режимы

- **Миссии для новичков** — интерактивные истории от лица пешехода (6 ситуаций).
- **Сдал на ВУ** — 15 задач по ПДД с картинками, как в экзаменационных билетах.
- **Вопросы по ПДД от нейросети** — генерация новых вопросов с 3 вариантами ответа.

Прогресс (очки, уровень, статус миссий) сохраняется в `localStorage`.

## Технологии

- React + TypeScript + Vite
- Tailwind CSS + кастомные компоненты UI
- React Router
- @tanstack/react-query
- NeuroAPI (OpenAI-совместимое API) для генерации вопросов

## Запуск проекта

```bash

# режим разработки
npm run dev

# сборка production

# предпросмотр собранной версии
